# «Лайт ПДД» — Telegram-бот

Бот продаёт доступ к закрытой группе (видео-разборы всех 40 билетов ПДД + чат с учениками)
и даёт бесплатный тренажёр по билетам. Основа — проверенная воронка первого бота, все тексты
сохранены; имя автора, название, поддержка и ссылки задаются в `.env` или прямо в админке.

## Как идёт клиент

```
Описание бота («Что умеет этот бот?») → /start
   │
   ▼
Приветствие + ссылка на канал по желанию: [📢 Подписаться] [➡️ Продолжить]
   │
   ▼
«Рад тебя видеть» — кто автор и что он сделал → [⭐ ПОКАЗАТЬ]
   │
   ▼
Видео-показ + «Вот как это выглядит» → [👑 ПОЛУЧИТЬ ДОСТУП]
   │
   ▼
Оффер: 1490 ₽, доступ навсегда → [💳 Оплатить по СБП] [🎟 Ввести промокод] [💬 Поддержка]
   │
   ▼
«Оплатить по СБП» → [💳 Оплатить] (ссылка Paydex) [✅ Я оплатил] → админ подтверждает
   │
   ▼
Бот сам присылает одноразовую ссылку в закрытую группу (разборы + чат)
```

**Меню внизу:** 👑 Видеоразборы · 📝 Тренировка · 👥 Отзывы · ❓ Частые вопросы · ℹ️ Информация · 💬 Поддержка.
У админа дополнительно — 🛠 Админка.

- **Видеоразборы** — купившим даёт ссылку в группу, остальным показывает оффер.
- **Тренировка** — 🎫 по билетам и 🎯 экзамен (см. «База вопросов»).
- **Частые вопросы** — ответы на типичные вопросы.
- **Информация** — об авторе и боте + ссылки на соглашение и политику (если заданы).
- **Отзывы** — по 5 на страницу; добавляются и удаляются в админке.
- У каждого раздела нижнего меню есть кнопка «⬅️ Назад».
- **Поддержка** — кнопка в личку `MANAGER_USERNAME`.

Бот молчит в группах и каналах — общается только в личке. Админ может проходить покупку
повторно сколько угодно раз (для проверки).

## Дожимающие сообщения

Отправляются автоматически и **только тем, кто не купил** — раз в 6 часов, каждый раз новое
сообщение со своим доводом (почему зубрёжка не работает, чат с поддержкой,
проверь себя экзаменом и т.д.). Повторов нет.

- Не подписан на канал → первым приходит просьба подписаться.
- Открывал оплату, но не оплатил → один раз приходит «вижу, ты открыл оплату».
- Ночью (23:00–9:00 по Москве) не пишем — сообщение переносится на 9:00.
- После покупки рассылка сразу прекращается. Всего ~20 сообщений (≈5 дней), потом бот замолкает,
  чтобы не превращаться в спам.

Тексты можно поменять в «✏️ Тексты → 🔔 Дожимающие сообщения». Порядок и интервал — в `bot/content.py`
(`FOLLOWUP_ORDER`, `FOLLOWUP_INTERVAL`).

## Админка (кнопка «🛠 Админка» или /admin)

- **📊 Статистика** за сегодня / 7 дней / всё время: зашли → подписались → смотрели показ →
  дошли до оплаты → нажали «оплатить» → купили, с процентами, выручка, результаты экзамена,
  источники трафика.
- **👥 Пользователи** — списки прямо в боте: «дошли до оплаты, но не купили», «купили», «все».
- **💳 Ждут подтверждения** — чеки, которые прислали клиенты (временная оплата по СБП).
  Кнопки «✅ Подтвердить» / «❌ Отклонить». После подтверждения бот сам выдаёт ссылку.
- **📣 Рассылка** — всем / кто не купил / кто купил. Можно текст, фото, видео — что угодно.
- **🎁 Выдать доступ** — вручную по ID, @username или пересланному сообщению.
- **🎬 Видео в воронке** — видео-показ канала и видео к напоминаниям (напоминание = видео + текст + «Получить доступ»; несколько видео чередуются).
- **⭐ Отзывы** — добавить отзыв (текст + имя или @username автора) и удалить.
- **✏️ Тексты** — поменять любой текст бота (см. ниже).
- **🎨 Кнопки: цвет и эмодзи** — цвет групп кнопок и премиум-эмодзи на кнопках (см. ниже).
- **⚙️ Настройки** — название бота, имя автора, username поддержки, ссылки на соглашение,
  политику и оплату. Значение из админки важнее, чем из `.env`.
- **🧹 Очистка** — очистить всех пользователей и статистику или удалить одного пользователя (с подтверждением).

О каждой покупке приходит уведомление.

## Оплата

Кнопка «💳 Оплатить по СБП» ведёт на многоразовую ссылку Paydex из `PAYMENT_URL`. Под ней —
«✅ Я оплатил»: клиент присылает скрин чека, админу приходит уведомление с кнопками
«Подтвердить / Отклонить», после подтверждения бот сам выдаёт ссылку в группу.
Пока `PAYMENT_URL` не задан, кнопки «Оплатить» нет: бот показывает реквизиты из `PAYMENT_DETAILS`
или просит написать в поддержку.

## Источники трафика

Давай в разные места разные ссылки — в статистике будет видно, откуда покупают:

```
https://t.me/ИМЯ_БОТА?start=insta
https://t.me/ИМЯ_БОТА?start=tiktok
```

## Тексты (админка → ✏️ Тексты)

Все тексты воронки, оплаты, меню, тренажёра, дожимающие сообщения и описание бота можно
поменять прямо в боте:

1. «🛠 Админка → ✏️ Тексты» → раздел → текст. Бот присылает текущий текст как есть.
2. «✍️ Заменить» → пришли новый текст **одним сообщением**. Форматирование Telegram
   (жирный, курсив, ссылки, цитаты, премиум-эмодзи) сохраняется.
3. Слова в фигурных скобках — плейсхолдеры (`{price}`, `{author}`, `{link}`…): бот подставит туда
   цену, имя и т.п. Список доступных показывается под каждым текстом.
4. Бот проверит текст (неизвестные плейсхолдеры, непарные скобки, обязательный `{link}`
   в «Спасибо за покупку», длину, разметку — пробной отправкой) и покажет, как он будет выглядеть.
   Сохраняется только после «✅ Сохранить».
5. «↩️ Сбросить к стандартному» — вернуть исходный текст.

Изменённые тексты хранятся в базе (таблица `settings`), стандартные — в `bot/content.py`.

## Цвет кнопок и премиум-эмодзи (админка → 🎨 Кнопки)

Telegram (Bot API 9.4+, у нас aiogram 3.31) поддерживает:

- **Цвет кнопки** — только 3 варианта: 🔵 синий (`primary`), 🟢 зелёный (`success`),
  🔴 красный (`danger`), или обычный. Свой оттенок задать нельзя. В боте цвет выбирается для группы:
  главные кнопки, оплата, остальные, «Назад», нижнее меню. Видно в свежих версиях Telegram,
  в старых кнопка будет обычной.
- **Премиум-эмодзи на кнопке** (перед текстом, вместо обычного эмодзи) и **в текстах**.
  Работает, только если у **владельца бота есть Telegram Premium** или у бота есть
  **дополнительный username, купленный на Fragment**. Чтобы задать эмодзи для кнопки, пришли его
  боту (нужен Premium у тебя) или его ID числом — бот сначала проверит, разрешает ли Telegram.
  В тексты премиум-эмодзи вставляются просто при редактировании текста.
- Если Premium закончится, бот не сломается: сообщение уйдёт без премиум-эмодзи (с обычными),
  а в «🎨 Кнопки» появится предупреждение.
- У кнопок нижнего меню — только цвет: их текст должен совпадать с подписью.

## Запуск локально

1. Создай **нового** бота у @BotFather (отдельно от первого бота), получи токен. Там же можно
   загрузить картинку-обложку: *Edit Bot → Edit Description Picture*. Текст описания бот поставит
   сам при запуске (его можно поменять в «✏️ Тексты → 🤖 Описание бота»).
2. `cp .env.example .env` и заполни минимум `BOT_TOKEN`, `ADMIN_IDS`, `AUTHOR_NAME`.
   Ссылки (канал, группа, оплата, документы) можно оставить пустыми — бот работает и без них.
3. Закрытая группа подключается без правки файлов: добавь бота **администратором** (с правом
   «Пригласительные ссылки») в группу с разборами — бот сам спросит, что это за чат.
4. Запусти:

```bash
pip install -r requirements.txt
python -m bot
```

Или в Docker:

```bash
docker build -t litepdd-bot .
docker run -d --restart=always --env-file .env -v litepdd_db:/db litepdd-bot
```

## Запуск на VPS (Ubuntu 22.04+ / Debian 12+)

Можно на отдельном сервере или **на том же, где уже работает первый бот** (`/opt/pdd-bot`,
сервис `pdd-bot`). У «Лайт ПДД» всё своё: папка `/opt/litepdd-bot`, сервис `litepdd-bot`,
системный пользователь `litepddbot`, база `/opt/litepdd-bot/litepdd_bot.db`. Первый бот не затрагивается.

**Установка — одна команда** (подключись к серверу по SSH и вставь):

```bash
curl -fsSL https://raw.githubusercontent.com/reshatmemetov01/litepdd/claude/litepdd-bot/deploy/install.sh | sudo bash
```

Скрипт поставит Python, скачает бота из этого репозитория, спросит токен, ID админов, название,
имя автора и username поддержки, и включит автозапуск. Если вставить токен, который уже
использует другой бот на этом сервере, скрипт попросит другой.

> Ветку можно поменять так: `curl ... | sudo BRANCH=main bash`

**Если репозиторий приватный**, сервер не сможет скачать код без доступа. Два варианта:
сделать репозиторий публичным (секретов в нём нет — токен и ID только в `.env` на сервере)
или создать на GitHub токен только для чтения (*Settings → Developer settings → Fine-grained tokens*,
доступ к `litepdd`, *Contents: Read-only*) и поставить так:

```bash
T=ТОКЕН; curl -fsSL -H "Authorization: token $T" https://raw.githubusercontent.com/reshatmemetov01/litepdd/claude/litepdd-bot/deploy/install.sh | sudo GITHUB_TOKEN=$T bash
```

**Обновление** — тоже одна команда:

```bash
sudo bash /opt/litepdd-bot/deploy/update.sh
```

Полезное:

```bash
sudo systemctl status litepdd-bot      # работает ли бот
sudo journalctl -u litepdd-bot -f      # логи в реальном времени (выход — Ctrl+C)
sudo nano /opt/litepdd-bot/.env        # поменять настройки, потом: sudo systemctl restart litepdd-bot
```

> Каждый бот (токен) должен быть запущен **только в одном месте** — иначе Telegram выдаёт ошибку конфликта.

## Документы продавца

`docs/legal.py` — **шаблон** соглашения и политики с плейсхолдерами `[ПРОДАВЕЦ]`, `[ИНН]` и т.п.
Документы прежнего продавца не используются. Когда будут данные нового продавца — заполни их,
перечитай текст, опубликуй (`python docs/legal.py publish <токен telegra.ph>`; пока не заполнено,
скрипт откажется) и укажи ссылки в `.env` (`AGREEMENT_URL`, `PRIVACY_URL`) или в «⚙️ Настройки».

## База вопросов

Исходники билетов лежат в `raw/`: `biletN.txt` (вопросы, ответы, пояснения) и `kartinkiN/` (картинки
билета N). Сейчас в тренажёре билеты 1–5. Чтобы добавить билеты:

1. Загрузи `biletN.txt` и папку `kartinkiN` в `raw/`.
2. Выполни `python tools/import_tickets.py` — он проверит билеты (20 вопросов, ответы, картинки)
   и пересоберёт `data/questions.json` и `data/images/`.
3. Обнови бота на сервере (`update.sh`).

**Тренировка** в боте:
- 🎫 **По билетам** — 20 вопросов билета по порядку с пояснениями, в конце итог.
- 🎯 **Экзамен** — 20 случайных вопросов, на 3-й ошибке экзамен заканчивается.

Ссылка `https://t.me/ИМЯ_БОТА?start=ticket_5` сразу запускает тест по 5-му билету —
её удобно ставить под видео-разбором билета в группе («Пройти тест»).

## Тесты

`python tests/test_bot.py` (или `pytest`) — прогоняет покупку, отклонение оплаты, дожим, экзамен,
билеты, админку, редактирование текстов, настройки, цвет/эмодзи кнопок и работу без ссылок —
без подключения к Telegram.
